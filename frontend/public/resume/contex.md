Auto 2000 Rantau Prapat:
1. Dealership Portal (toyotarantauprapat.com) + Gemini AI Recommendation
"Boosted customer lead generation by shipping a Next.js dealership portal with Gemini AI car recommendations."

Situation: Cabang Auto2000 Rantauprapat membutuhkan kanal pemasaran digital terpusat untuk menampilkan katalog unit Toyota, layanan purna jual (after sales), profil tim sales, dan simulasi kredit, sementara calon pembeli sering kebingungan memilih unit yang paling sesuai dengan kebutuhan dan anggaran mereka.

Task: Bersama tim, merancang dan membangun aplikasi web promosi cabang yang interaktif serta mengintegrasikan fitur rekomendasi kendaraan berbasis AI agar calon pelanggan lebih mudah menemukan unit yang tepat dan masuk ke jalur prospek (lead).

Action: Mengembangkan portal web menggunakan Next.js dan TypeScript (dengan dukungan komponen antarmuka modern dan state management yang terstruktur), menyusun halaman katalog kendaraan, profil sales, dan simulasi kredit, serta menghubungkannya ke Gemini API dengan konteks data kendaraan agar sistem mampu memberikan rekomendasi mobil yang relevan secara interaktif.

Result: Berhasil merilis portal promosi cabang (toyotarantauprapat.com) dalam siklus kerja praktik dengan alur informasi produk dan simulasi kredit yang terstandar serta fitur rekomendasi AI yang membantu mengarahkan minat calon pembeli ke tim sales.

2. Internal STNK/BPKB Reminder Web App + WhatsApp API
"Cut admin notification delays by building an internal STNK/BPKB reminder app with WhatsApp API alerts."

Situation: Staf administrasi di dealer harus mengelola pendataan pengambilan dokumen kendaraan (STNK dan BPKB) serta menghubungi pelanggan secara manual untuk pengingat, yang rawan terlambat atau terlewat ketika volume dokumen menumpuk.

Task: Membangun aplikasi web internal yang aman dan terstruktur untuk memusatkan data pelanggan dokumen kendaraan, melacak status pengingat, mendukung impor/ekspor data Excel, dan mengirim notifikasi otomatis melalui WhatsApp API.

Action: Merancang alur aplikasi web berbasis Extreme Programming (XP) lengkap dengan autentikasi pengguna (login), manajemen data pelanggan, fitur impor/ekspor Excel untuk memudahkan sinkronisasi data administrasi, pencatatan status pengiriman reminder, serta integrasi WhatsApp API untuk mengirim pesan pengingat berformat konsisten, diikuti pengujian fungsional (Black Box, White Box, dan Equivalence Partitioning).

Result: Mengurangi keterlambatan pemberitahuan dokumen ke pelanggan dan mempercepat alur kerja staf administrasi melalui pengiriman notifikasi otomatis serta pelacakan status pengingat yang lebih rapi.

3. Automated Sales Lead Routing Pipeline (Google Apps Script)
"Eliminated manual lead sorting by developing a Google Apps Script pipeline to route prospect data per sales rep."

Situation: Data calon pelanggan (leads) yang tertarik pada unit Toyota masuk melalui Google Form ke Google Spreadsheet, sehingga tim sales masih perlu memilah data per tenaga penjual dan memantau jadwal follow-up secara manual.

Task: Mengotomatisasi pemisahan data prospek berdasarkan nama masing-masing sales dan menyiapkan pengingat otomatis sesuai jadwal follow-up yang telah ditentukan.

Action: Menulis skrip otomasi berbasis Google Apps Script (JavaScript) yang terhubung dengan Google Form dan Google Spreadsheet untuk mempartisi data masuk ke lembar/kelompok per sales representative secara otomatis serta memicu pengingat sesuai jadwal follow-up.

Result: Menghilangkan proses penyortiran prospek secara manual dan membantu tim sales menindaklanjuti jadwal follow-up tepat waktu dengan risiko data terlewat yang jauh lebih kecil.

4. Python Script for Excel Data Cleaning (~38k+ Records / 15 Years)
"Built a Python script to automate Excel data-cleaning across 38k+ records (15 years), eliminating manual work."

Situation: Arsip data historis operasional/administrasi dalam format Excel mencakup lebih dari 38.000 baris selama rentang waktu sekitar 15 tahun, sehingga pembersihan dan standardisasi data secara manual sangat lambat dan rentan human error.

Task: Membuat skrip pemrosesan data otomatis agar puluhan ribu baris data lintas tahun dapat dibersihkan, dinormalisasi, dan disiapkan dengan cepat dan akurat.

Action: Mengembangkan skrip Python untuk membaca file Excel berukuran besar, menangani inkonsistensi format/nilai kosong/duplikat secara terprogram, serta menghasilkan keluaran data yang bersih dan siap dipakai untuk analisis maupun pemrosesan lanjutan.

Result: Menghilangkan pekerjaan pembersihan data manual berulang pada dataset 38k+ baris (15 tahun) dan mempercepat penyiapan data dengan konsistensi yang jauh lebih tinggi.
